# هدوء — Hadaa

تطبيق أندرويد يشغّل أصواتًا تساعد الطفل على النوم. بلا توقيت، وبلا انقطاع عند إطفاء الشاشة.

---

## ما الذي تغيّر عن النسخة السابقة

| المشكلة | الحل في هذه النسخة |
|---|---|
| الصوت يتوقف بعد دقائق عند إطفاء الشاشة | خدمة أمامية (Foreground Service) بإشعار دائم + `foregroundServiceType="mediaPlayback"` |
| المعالج ينام فيتوقف توليد الصوت | قفل استيقاظ جزئي `PARTIAL_WAKE_LOCK` طوال التشغيل |
| النظام يقتل التطبيق لتوفير البطارية | زر داخل التطبيق يطلب استثناءه من تحسين البطارية |
| التطبيق يموت عند مسحه من «التطبيقات الأخيرة» | `stopWithTask="false"` + `onTaskRemoved` لا يوقف شيئًا |
| التوقيت غير مرغوب | أُزيل بالكامل |
| الأزرار صغيرة | زر دائري كبير 176dp + بطاقات أصوات كبيرة |
| لا يوجد إيقاف سريع | زر «⏹ إيقاف» واضح في الشريط المنسدل |
| لا توجد نافذة على شاشة القفل | `MediaSessionCompat` + `MediaStyle` مربوطة بالرمز المميّز للجلسة |
| عدد الأصوات قليل | 20 صوتًا في أربع مجموعات، منها ضجيج أبيض ووردي وبني حقيقية |
| لا يمكن تقوية الصوت أكثر | ثلاث درجات قوة بضغط ديناميكي: الدرجة القوية ‎+12 dB‎ تقريبًا |

الأصوات تُولَّد داخل الجهاز رياضيًا (بلا ملفات صوتية)، فلا توجد «فاصلة» مسموعة عند التكرار، والتطبيق صغير جدًا ويعمل إلى ما لا نهاية.

## كيف تحصل على ملف APK (مجانًا، بلا برامج)

1. أنشئ حسابًا على [github.com](https://github.com) إن لم يكن لديك.
2. اضغط **New repository** → سمِّه `hadaa` → اختر **Private** → **Create**.
3. اضغط **uploading an existing file** وارفع محتويات هذا المجلد (أو ملف الـ zip بعد فكّه).
4. افتح تبويب **Actions** → ستجد مهمة `Build APK` تعمل تلقائيًا. انتظر حوالي 3–5 دقائق.
5. افتح المهمة بعد انتهائها → في الأسفل قسم **Artifacts** → نزّل `Hadaa-APK`.
6. فكّ الضغط وثبّت `app-debug.apk` على الجوال (سيطلب منك السماح بالتثبيت من مصدر غير معروف).

بديل: افتح المشروع في Android Studio واضغط **Run**.

## بعد التثبيت — خطوتان مهمتان

1. عند أول تشغيل اسمح بالإشعارات. **الإشعار هو ما يبقي الصوت حيًّا**، فلا تحجبه.
2. إذا ظهرت البطاقة الصفراء «خطوة واحدة مهمة»، اضغطها واختر **السماح / غير مقيّد**.

على أجهزة Samsung و Xiaomi و Huawei و Oppo أضف يدويًا:
- **Samsung**: الإعدادات ← البطارية ← حدود الاستخدام في الخلفية ← تأكد أن التطبيق ليس في «التطبيقات النائمة»
- **Xiaomi**: الإعدادات ← التطبيقات ← هدوء ← توفير البطارية ← **بلا قيود**، وفعّل **التشغيل التلقائي**
- **Huawei**: الإعدادات ← البطارية ← تشغيل التطبيقات ← هدوء ← إدارة يدوية ← فعّل الثلاثة

## بنية المشروع

```
app/src/main/java/com/mohammad/hadaa/
  MainActivity.kt    الواجهة: الأزرار، البطاقات، مستوى الصوت
  PlayerService.kt   الخدمة الأمامية — هنا الإصلاح الأساسي
  NoiseEngine.kt     توليد الصوت عبر AudioTrack
  SoundPreset.kt     قوالب الأصوات الثمانية
```

لإضافة صوت جديد: أضف `SoundPreset` في `SoundPresets.all` ونصًّا في `strings.xml`.
